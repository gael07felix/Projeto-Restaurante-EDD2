# Projeto Restaurante

Projeto da disciplina de POO / MVC - Console Application.

## Funcionalidades

- Criar novo pedido
- Adicionar item ao pedido
- Remover item do pedido
- Consultar pedido
- Cancelar pedido
- Listar todos os pedidos
- Calcular soma geral dos pedidos do dia

## Limites

- Até 50 pedidos
- Até 10 itens por pedido

## Estrutura

- Models
- Controllers
- Views
- Program.cs
